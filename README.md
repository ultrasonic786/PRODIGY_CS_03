# Password Complexity Checker 🔐

## 📌 Task 03 - Prodigy InfoTech Cyber Security Internship

This project is a Python-based Password Complexity Checker that evaluates the strength of a password based on important security criteria.

---

## 🔎 Features

- Checks minimum length (8+ characters)
- Detects uppercase letters
- Detects lowercase letters
- Detects numeric digits
- Detects special characters
- Provides strength rating:
  - Weak ❌
  - Moderate ⚠
  - Strong 💪
- Gives suggestions to improve weak passwords

---

## 🛠 Technologies Used

- Python 3
- Regular Expressions (`re` module)

---

## 🚀 How It Works

The program assigns a score based on different password conditions:

- Length check
- Uppercase presence
- Lowercase presence
- Number presence
- Special character presence

Based on the score, it determines password strength and provides feedback for improvement.
